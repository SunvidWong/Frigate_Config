# 🎉 Frigate Configuration Tool - Phase 8 Release Notes

**版本**: Phase 8 Complete
**发布日期**: 2025-10-10
**代号**: Disk & Volume Mapping

---

## 📢 发布公告

我们很高兴地宣布 **Frigate Configuration Tool Phase 8** 正式发布！

这个版本带来了全新的**磁盘与卷映射管理功能**,让您轻松配置 Frigate 的存储位置,优化录像和剪辑的存储策略。

---

## 🎯 新功能

### 1. 磁盘空间检查 🗄️
- ✅ 检查任意路径的磁盘使用情况
- ✅ 显示总容量、已用、可用空间
- ✅ 人性化显示 (自动转换 GB/TB)
- ✅ 彩色进度条 (绿/黄/红)
- ✅ 低空间警告 (< 10GB)
- ✅ 跨平台支持 (macOS/Linux/Windows)

**使用场景**:
```
输入路径: /Users/username
点击"检查磁盘空间"
→ 立即看到该路径所在磁盘的详细信息
```

### 2. 智能存储推荐 🧠
- ✅ 基于可用容量的智能推荐
- ✅ 自动扫描常用挂载点
- ✅ 显示推荐用途 (录像/剪辑/缓存)
- ✅ 容量分级建议:
  - 100GB+ → 适合录像
  - 20GB+ → 适合剪辑
  - 10GB+ → 适合缓存

**使用场景**:
```
点击"扫描推荐路径"
→ 查看系统推荐的存储位置
→ 选择最合适的路径用于不同用途
```

### 3. 卷映射管理 📁
- ✅ 可视化卷映射配置
- ✅ CRUD 操作 (创建/读取/更新/删除)
- ✅ 4种映射类型:
  - 🎥 **Recordings**: 录像存储
  - ✂️ **Clips**: 剪辑存储
  - 💾 **Cache**: 临时缓存
  - ⚙️ **Config**: 配置文件
- ✅ 实时路径验证
- ✅ 错误提示和帮助

**使用场景**:
```
添加新映射:
1. 选择类型: Recordings
2. 输入路径: /mnt/storage/recordings
3. 系统验证: ✅ 路径有效
4. 添加到列表
```

### 4. 快速默认设置 ⚡
- ✅ 一键创建 4 个默认映射
- ✅ 自动配置推荐路径:
  - `~/frigate/config`
  - `~/frigate/recordings`
  - `~/frigate/clips`
  - `~/frigate/cache`

**使用场景**:
```
新用户首次使用:
点击"使用默认路径"
→ 4个卷映射自动创建
→ 立即可用,无需手动配置
```

### 5. Docker 命令预览 🐳
- ✅ 自动生成 Docker `-v` 命令
- ✅ 显示所有映射的摘要
- ✅ 一键复制用于部署
- ✅ 命令格式:
  ```
  -v /host/path:/container/path
  ```

**使用场景**:
```
配置完卷映射后:
滚动到底部 → 查看"映射摘要"
→ 复制 Docker 命令
→ 用于实际 Frigate 部署
```

### 6. 路径验证 ✅
- ✅ 检查路径存在性
- ✅ 验证是否为目录
- ✅ 检查写权限
- ✅ 实时反馈 (✅/❌)
- ✅ 详细错误消息

**验证内容**:
- 路径必须存在
- 必须是目录 (非文件)
- 必须可写入

### 7. 部署页面集成 🔗
- ✅ 在部署页面显示卷映射状态
- ✅ 快速链接到磁盘映射配置
- ✅ 无缝工作流集成

## ⚠️ 已知问题与限制

### 非阻塞问题

#### 1. 卷映射持久化
**当前**: 卷映射仅在会话中存储
**计划**: Phase 9 将添加持久化存储
**影响**: 应用重启后需要重新配置映射
**缓解**: 记录您的配置或使用 Docker 命令导出

#### 2. 实时监控
**当前**: 磁盘空间需手动刷新
**计划**: 未来版本添加自动监控
**影响**: 需要手动点击刷新查看最新数据
**缓解**: 定期点击刷新按钮

#### 3. 多平台二进制
**当前**: 仅提供 macOS x86_64 构建
**可用**: 代码支持所有平台
**计划**: 提供 Linux 和 Windows 构建
**缓解**: Linux/Windows 用户需要从源码构建

### 预存在问题 (非 Phase 8)

#### 状态管理警告
**表现**: 控制台可能出现状态管理相关警告
**影响**: 低 - 不影响 Phase 8 功能
**状态**: 已知,计划修复

## 🎓 使用示例

### 场景 1: 首次配置存储
```
1. 启动应用
2. 导航到 "磁盘映射" 页面
3. 点击 "使用默认路径"
4. ✅ 4 个映射自动创建
5. 滚动到底部复制 Docker 命令
6. 在 Frigate 部署中使用
```

### 场景 2: 检查磁盘空间
```
1. 在 "磁盘空间检查" 区域
2. 输入路径: /mnt/storage
3. 点击 "检查磁盘空间"
4. ✅ 查看容量、进度条、警告
5. 决定是否使用该路径
```

### 场景 3: 多磁盘配置
```
使用 SSD 做缓存:
- 类型: Cache
- 路径: /mnt/ssd/frigate-cache

使用 HDD 做录像:
- 类型: Recordings
- 路径: /mnt/hdd/frigate-recordings

使用小盘做配置:
- 类型: Config
- 路径: ~/frigate/config
```
